# Resume Builder

A full-stack web application for creating professional resumes.

## Tech Stack
- **Frontend**: React + Vite + TypeScript + TailwindCSS + shadcn/ui + TanStack Router
- **Backend**: Django + Django REST Framework + SQLite

## Local Development

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
Runs on http://localhost:5173
